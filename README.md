# Hi, I'm born-lucky ☦️

I build independent systems and games, mostly around AI agents, memory, and spatial tools. Everything here is public and non-profit until a company hires me. If something is useful to you, use it, fork it, or say hello.

## What I'm building

- **[All-Mind](https://github.com/born-lucky/all-mind)** — a desktop memory palace for notes, files and AI sessions. Houses inside houses, memories judged good or bad, a timeline for what you're done with, and a bridge so Claude Code walks the same palace you do. Windows, macOS, Linux.
- **[4d-memory](https://github.com/born-lucky/4d-memory)** — a 4D memory harness for AI agents. A mnemonic palace on a Z⁴ lattice, with valence as the fourth axis. MIT.
- **[hoodoo](https://github.com/born-lucky/hoodoo)** — an open-source landscape world builder for humans and agents. MCP-first, plugin-ready.
- **[3d-aim-engine](https://github.com/born-lucky/3d-aim-engine)** — J-Space Aim & Paint. A Godot 4 aim trainer and spatial paint studio: scenario builder, path editor, map builder, Greek alphabet motor lab, headless regression suites.

## How I like to work

- Plain files over databases. Markdown you can grep beats a format you can't leave.
- MCP-first, so agents and people use the same doors.
- Headless tests for everything, including the visual stuff.
- Tools, not habits. No streaks, no badges, one thing at a time.
